# CineMind AI — интеллектуальный десктопный каталог фильмов

**Проект:** «Жасанды интеллект технологиялары негізінде фильмдерді іздеу, жүйелеу, салыстырмалы талдау және пайдаланушы талғамына сәйкес жеке ұсыныстар ұсынуға арналған интеллектуалды десктоптық қосымшаны әзірлеу».

**Участники:** Жолдыбай Мадина, Каримуллаев Мухамедияр.

## Запуск (Windows)

1. Скачайте архив, распакуйте его полностью в папку `CineMind_AI`.
2. Установите **Python 3.10 или новее** с https://python.org и включите **Add python.exe to PATH**.
3. Дважды нажмите `start.bat`, либо откройте терминал в этой папке и введите `py -3 app.py`.
4. Нажмите «Создать аккаунт», зарегистрируйтесь, войдите и изучите каталог. Файл `cinemind.db` создаётся автоматически при первом запуске.

Не нужно устанавливать Flask, Qt, Pandas или API-ключи. Проект использует **Tkinter**, **SQLite** и стандартную библиотеку Python.

## Структура

- `app.py` — окна, дизайн, навигация, формы, графики, уведомления, экспорт.
- `database.py` — база SQLite, таблицы, каталог, история и 18 демонстрационных фильмов.
- `security.py` — регистрация, вход, PBKDF2-хеширование, изменение и сброс пароля.
- `intelligence.py` — ИИ-рекомендации TF-IDF, косинусная близость, сравнение альтернатив по весам.
- `mailer.py` — SMTP-письма, вынесенные настройки.
- `test_project.py` — автоматические тесты бизнес-логики.
- `start.bat` — запуск на Windows.

## Функции

1. Дизайн интерфейса (реализован самостоятельный тёмный Tkinter-дизайн, **не точная копия Figma**).
2. Регистрация с уникальным email и безопасным хранением паролей.
3. Авторизация и запрет доступа к каталогу без входа.
4. Профиль: изменение имени, почты.
5. Пароль: изменение, восстановление кодом на почту (SMTP требуется).
6. Навигация по 8 разделам.
7. SQLite: связанные таблицы, создание/чтение/редактирование/удаление фильмов.
8. Поиск, фильтр по жанру, сортировка.
9. Статистика: средний рейтинг, количество и диаграмма жанров.
10. Решение по методу взвешенных критериев (рейтинг 50%, новизна 30%, краткость 20%).
11. Локальные ИИ-рекомендации по описаниям и избранным фильмам.
12. Email-отправка отчётов (SMTP требуется).
13. Проверка данных, сообщения об ошибках и подтверждения действий.
14. История операций текущего пользователя с поиском.
15. Экспорт отчётов TXT и CSV.
16. Завершение сеанса и возврат на экран входа.
17. Автоматические тесты, сценарии ручной проверки.
18. Документация (этот файл и `DEFENSE.md`).
19. Подготовка к защите (демонстрационный сценарий и ответы в `DEFENSE.md`).

## Как пользоваться

- Каталог: выделите запись, нажмите «★ Избранное», «Изменить», «Удалить» или «⇄ К сравнению». Для сравнения выделите сразу несколько фильмов (Ctrl + щелчок) и нажмите кнопку.
- ИИ-рекомендации: напишите несколько ключевых слов, например «космос наука». Алгоритм ранжирует фильмы и показывает объяснение.
- Сравнение: сначала добавьте не менее двух фильмов из каталога. В результате получите таблицу и лучший вариант.
- Статистика: откройте экран с графиком жанров.
- История: поиск по действиям и результатам.
- Отчёты: сохраните TXT/CSV или отправьте содержание отчёта по почте.

## SMTP (необязательная настройка)

Без SMTP приложение работает **кроме отправки писем и сброса пароля по email**. Нужно использовать действительный SMTP-сервис и его специальный пароль приложения (не хранить секрет в проекте).

В Windows PowerShell *в той же сессии перед запуском*:

```powershell
$env:CINEMIND_SMTP_HOST = 'smtp.gmail.com'
$env:CINEMIND_SMTP_PORT = '587'
$env:CINEMIND_SMTP_USER = 'your-address@gmail.com'
$env:CINEMIND_SMTP_PASSWORD = 'your-app-password'
py -3 app.py
```

Замените адрес и пароль на свои. Отправка требует интернета и корректного SMTP-провайдера. Код сброса действителен 10 минут. При ошибке отправки код не показывается в интерфейсе.

## Проверка

```powershell
py -3 test_project.py
```

Тесты создают отдельную временную БД. Автоматизированно проверены регистрация, неправильный пароль, смена/сброс пароля, создание/редактирование/удаление фильмов, поиск, сортировка, сравнение и ИИ для **трёх наборов ключевых слов**.

Ручная проверка на Windows: интерфейс и навигация; взаимодействие с Figma; отправка реального письма при наличии SMTP; поведение диалогов; удобство в нужном разрешении. Эти проверки не автоматизированы и должны быть проведены вами.

## Важные ограничения

- Система рекомендаций — **контентный NLP-алгоритм TF-IDF**, не большая нейросеть и не облачная генеративная модель.
- Демонстрационные названия, годы и рейтинги для учебного примера; не заявляйте, что рейтинги синхронизируются с IMDb.
- Фильмы общие для всех аккаунтов: **роли администратора нет**. Для реального многопользовательского сервиса нужны разграничение прав, блокировка подбора паролей и дополнительные меры безопасности.
- Отчёты не являются PDF: доступны TXT/CSV. Скриншоты пользовательского интерфейса нужно добавить после запуска.
